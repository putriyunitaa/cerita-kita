# Cerita Kita

Proyek aplikasi web "Cerita Kita" yang terdiri dari frontend dan backend.

## Struktur Direktori
- `frontend/` - Berisi file antarmuka pengguna (HTML, CSS, JavaScript).
- `backend/` - Berisi server Node.js dan konfigurasi database.

## Cara Menjalankan

### Backend
1. Buka terminal dan arahkan ke direktori `backend/`.
2. Jalankan `npm install` untuk menginstal semua dependensi.
3. Jalankan `node server.js` untuk menjalankan server backend.

### Frontend
1. Buka file `frontend/index.html` di browser Anda.
